# render

Presentation layer. Drawing characters on `stretch-gpu` (WebGPU).

- Skinned mesh passes with flat and two-tone shading and outlines.
- Color layers for painted regions and marks.
- Stroke ribbons for surface strokes and line work.
- The scene frame the panes render into.

**Uses:** `geom`, `stretch-gpu`.
**Used by:** `screens-core`.
**Tests:** need a GPU.

# Face and clothes

## Mouth group

A part's `groups` entry `{"id", "name", "roles": [{"role", "marks", "fill", "ink"}], "controls"}`. Roles draw in the order listed; a new mouth lists them in this order:

| draw | role | holds |
| --- | --- | --- |
| 1 | `inner` | the shape between the lips, filled with its `fill` slot, shown as the mouth opens |
| 2 | `tongue` | marks clipped to the inner shape |
| 3 | `teeth` | marks clipped to the inner shape |
| 4 | `lipLine` | the line of the closed mouth, drawn on the muzzle and wrapping round it; a group with one is a mouth |
| 5 | `corners` | short marks at the mouth's ends |

`controls`: `open` 0 closed to 1 open (drives the jaw joint and parts the lips), `width` scales it across, `mouthShape` (`SMILE`, `FROWN`, `O`, `GRIMACE`) bends the lip line, `expressionBlend` 0 at the group's own marks to 1 at the shown expression's. Each role's marks are mark ids on the same part.

## Garments

| question | answer |
| --- | --- |
| how far a cover stands off its part | the garment's `partFits` for that part, else its `fit`, else the cover's `ease` |
| where cloth stands off further | a cover's Side and Top `outlines`, along the part's own x, add to that |
| what a `redraw` lays over the part | outlines by view and parameters by key replace the part's; regions and marks replace by id, others kept; `color` replaces the base slot; `areas` by name |
| what a redraw starts from | the bare part; with several garments worn, the outermost garment that changes the part wins, its change alone applied |
| what a `swap` does | builds the part from the other template with only the swap's shape |
| a change on a pair | named by the left side, it holds for both sides, mirrored |
| order of garments | by `layer`, innermost first |

Fields as the schema describes them:

| field | meaning |
| --- | --- |
| garment `slot` | The wardrobe slot it goes in. |
| garment `layer` | Counted out from the skin: under a waistband 1, a waistband 2, over both 3. |
| garment `color` | Its palette slot. |
| garment `fit` | How far it stands off the body, in body units; each cover's own ease when left out. |
| garment `partFits` | A fit for one covered part (a pair by its left side), over the garment's. |
| garment `inkHem` | Whether its edges are inked. |
| garment `joins` | Covered parts whose join with the next covered part is inked. |
| garment `covers` | The parts it covers, one cover each; a pair's cover names its left side and covers both. |
| garment `changes` | What it does to body parts under it, by part (a pair by its left side). |
| garment `looseEnds` | Loose ends it hangs, as a scarf's tails. |
| cover `from` | Where along the part it starts. |
| cover `to` | Where along the part it ends. |
| cover `fromV` | Where round the part it starts; below 0 to cross v 0. |
| cover `toV` | Where round the part it ends. |
| cover `ease` | How far it stands off the part where no outline takes it further, when the garment has no fit. |
| cover `outlines` | Side and Top outlines along the part's own x where the cloth stands off further, as a skirt's flare. |
| change `hide` | The part is not built while the garment is worn. |
| change `through` | The part comes out through a hole: an armhole or neckline with cuff false, a collar or sleeve cuff with cuff true. |
| change `redraw` | The part keeps its template and takes this shape over its own: outlines and parameters by name, regions by id. |
| change `swap` | The part takes another template with this shape while the garment is worn, as a closed shoe swaps a foot for a blob. |
